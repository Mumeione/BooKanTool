# BookanTool — 博看书刊下载工具

把「博看」网站上的杂志和书籍，一键下载成 **PDF** 或 **EPUB** 电子书，保存到自己的电脑上，随时翻阅、无需联网。

## 📖 使用教程

### 第一步：拿到书刊链接

1. 在「博看」网站 https://new.bookan.com.cn 中打开你想下载的杂志 / 书籍
2. 复制浏览器**地址栏的网址**

### 第二步：粘贴并选择格式

1. 把链接粘贴进主界面的输入框（点「＋ 添加一行」可增加更多链接）
2. 选择导出格式（滑动小滑块）：
   - **自动** —— 推荐，优先EPUB
   - **PDF** —— 图片版，和纸质版排版一致，文件较大
   - **EPUB** —— 文字版，文件小、可调字号
3. 两个可选项：
   - **压缩图片**（仅 PDF）：压缩文件，画质略降；轻度 / 中度 / 高度三档
   - **章节书签**：在 ⚙ 设置菜单里，建议保持开启

### 第三步：开始下载

1. 点击 **「开始下载」**
2. 等待下载完成（中途想停下，点「取消下载」）
3. 完成后点 **「返回主页面」**；需要定位文件时，在结果卡片里点「打开所在文件夹」

> 默认保存位置：`C:\Users\你的用户名\BookanTool\downloads\`
> 想换地方？在 ⚙ 设置菜单里修改「输出目录」。

## ❓ 常见问题

**Q：提示「链接无法识别」？**
确认复制的是博看网站的书刊详情页链接，而不是首页或搜索页。

**Q：下载到一半失败了？**
重新点「开始下载」再试一次；还不行就换一条链接测试，判断是不是这本书的问题。可在 ⚙ 设置 → 运行日志里查看原因。

**Q：EPUB 打不开？**
EPUB 需要阅读软件支持，手机推荐「微信读书」导入，电脑可用 Calibre。

## 🧩 浏览器扩展版（免安装）

不想装桌面程序？**浏览器扩展版**（`extension/`，Manifest V3）直接在博看网页里下载，Edge / Chrome / Supermium 均可使用。

**功能一览**

- 书刊详情页「试读」按钮旁自动出现 **「下载」按钮**，点按弹出选项：输出格式（自动 / PDF / EPUB）、图片压缩三档、**下载全年**（杂志类，自动展开为逐期任务）
- 页面右侧**悬浮进度方块**：可拖动、站内跨页无缝同步，点击展开逐期进度与失败原因，完成后显示 √ / ×
- PDF 自带两级章节书签；压缩、目录换算与桌面版逻辑一致
- 设置、使用说明、运行日志收纳在扩展弹窗里，不干扰浏览

**安装（开发者模式加载）**

1. 下载 `BookanTool_extension_v1.0.0.zip` 并解压
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启右上角**「开发人员模式」**
3. 点**「加载解压缩的扩展」**，选择解压出的 `extension` 文件夹

**说明**

- 文件保存在浏览器**默认下载目录**的 `bookantool/` 文件夹中
- 批量下载建议在浏览器 设置 → 下载 中关闭**「下载开始时显示下载菜单」**（Edge）或**「下载时显示下载栏」**（Chrome），避免每完成一期弹出提示
- Windows 7 32 位可用 [Supermium](https://github.com/win32ss/supermium/releases) 加载；批量下载建议勾选压缩以控制内存占用
