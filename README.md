# BookanTool 安卓版 

在安卓手机 / 平板上，把博看书苑APP上的杂志和书籍，一键下载成 **PDF** 或 **EPUB** 电子书，随时翻阅、无需联网。

- 免 Root、免存储权限申请繁琐流程，产物直接保存到系统**下载**目录，文件管理器即可查看
- 与 PC 端共享同一套下载内核，支持期刊按期下载与全年批量、图书整本导出

---

## 📲 安装

1. 从 [Releases](https://github.com/Mumeione/BooKanTool/releases) 下载最新的 `bookantool-x.x.x-arm64-v8a-release.apk`
2. 在手机上打开 APK 安装（需允许「安装未知来源应用」）
3. 系统要求：Android 8.0+，64 位（arm64-v8a）设备

---

## 📖 使用教程

### 第一步：拿到书刊链接

在「博看书苑」APP 打开想下载的杂志 / 书籍，复制：
- **移动端分享链接**（如 `https://wk6.bookan.com.cn/?id=130#/dt/1/310823891`）

### 第二步：粘贴并选择格式

1. 把链接粘贴进输入框（点「＋ 添加一行」可增加更多链接）
2. 选择导出格式：
   - **自动** —— 推荐，优先 EPUB
   - **PDF** —— 图片版，和纸质版排版一致，文件较大
   - **EPUB** —— 文字版，文件小、可调字号
3. 可选项：
   - **压缩图片**（仅 PDF）：压缩文件，画质略降；轻度 / 中度 / 高度三档
   - **章节书签**：建议保持开启

### 第三步：开始下载

1. 点击 **「开始下载」**，实时显示进度，可随时取消
2. 期刊支持「下载全年」，一次加入同刊全年各期
3. 完成后点「打开下载文件夹」跳转系统文件管理器查看，或返回主界面继续下一本

> **保存位置**：`Download/bookantool/`（系统下载目录，固定不可更改）
> 支持多本连续下载，合并压缩在后台自动完成。

## ❓ 常见问题

**Q：提示「链接无法识别」？**
确认复制的是博看书刊详情页 / 分享链接，而不是首页或搜索页；纯 ID 输入已不再支持。

**Q：下载到一半失败了？**
重新点「开始下载」再试一次；可在 ⚙ 设置 → 运行日志里查看原因。

**Q：在文件管理器里找不到下载的文件？**
请查看系统**下载**目录下的 `bookantool` 文件夹；若曾重装应用，同名旧文件会被重命名（时间戳后缀）而不是覆盖。

**Q：EPUB 打不开？**
EPUB 需要阅读软件支持，推荐「微信读书」导入，或电脑使用 Calibre 管理转换。

**Q：切后台后回来卡住了？**
回到应用即可自动恢复握手；如长时间停留在「正在握手后端」，重启应用即可。

## 🛠 从源码构建

```bash
# 需要 WSL2 环境（buildozer 不支持原生 Windows）
bash devtools/wsl_sync_and_build.sh          # debug 包

```

依赖 Python 3、Kivy/p4a 工具链与 Android NDK，详见 `buildozer.spec`。PyPI / Rust 依赖建议使用国内镜像。
